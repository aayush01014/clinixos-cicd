5. Technical Discussion & Viva Questions

Q1: Why was Semi-Detached mode selected instead of Organic mode?
Hospital management software mandates high reliability, real-time bed inventory tracking, doctor/nurse workflow synchronization, and clinical data integrity. Unlike small standalone organic utility tools, ClinixOS involves intermediate complexity, rigorous domain requirements, and multi-user transactional workflows.
Q2: What is the primary difference between physical LOC and Function Points?
LOC (Lines of Code) measures the physical size of source code, which varies heavily based on programming language, formatting, and syntax. Function Points (FP) measure the actual business functionality and transactional utility delivered to end users, completely independent of the underlying implementation language. For ClinixOS, 10,834 LOC translates to 255.30 Function Points (~42 LOC/FP).
Q3: How does SQLite impact estimation and portability?
SQLite operates in-process as a serverless, self-contained relational database file. It eliminates external database server setup, connection pooling, and maintenance overhead, reducing Installation Ease complexity while guaranteeing full ACID transactions across any machine.
